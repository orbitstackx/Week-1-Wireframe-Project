# Brightpath Studio

## Week 1 Internship Project

Brightpath Studio is a responsive static webpage developed using HTML5 and CSS3 as part of the Week 1 internship task, Transforming Wireframes into Static Web Pages.

## Features

* Responsive navigation bar
* Hero section with call-to-action buttons
* Services section
* About Us section
* Client testimonials
* Contact form UI
* Responsive layout for different screen sizes

## Technologies Used

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Media Queries

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Explore the webpage.

## Project Objective

To practice semantic HTML, CSS styling, responsive web design and basic frontend development.
